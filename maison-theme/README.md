# Maison — thème Shopify

Thème Shopify indépendant (bijouterie/joaillerie, FR) importé tel quel depuis `maisontheme.zip`.
Ce dossier est un projet séparé, sans lien avec le reste du dépôt.

## Structure

- `layout/` — layout principal (`theme.liquid`)
- `sections/` — sections Shopify (accueil, collection, produit, éditorial, configurateur de bague, etc.)
- `snippets/` — snippets réutilisables
- `templates/` — templates JSON (pages, produit, collection, panier, recherche, favoris...)
- `assets/` — CSS/JS (`maison-*.css`, `maison-*.js`)
- `config/` — `settings_schema.json` / `settings_data.json`
- `locales/` — traductions (`fr.default.json`, `en.json`)

## État

Import initial complet, à conserver tel quel. Améliorations à venir sur indication.
